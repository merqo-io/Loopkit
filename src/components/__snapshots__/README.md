# components/**snapshots**

Vitest snapshot files for `src/components`.

## Contents

- `flame-layers.snapshot.dom.test.tsx.snap` - rendered DOM of the Flame Club flame layers across stages, pinning the owner-approved markup through the file split
- `scratch-card.snapshot.dom.test.tsx.snap` - rendered DOM of the Scratch Card overlay and cover states, pinning the owner-approved markup through the file split

Both files reference the role-named `--art-*` tokens and the `paper` tokens, so they change when a token is renamed.
